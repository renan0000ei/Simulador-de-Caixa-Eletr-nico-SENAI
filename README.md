# Simulador-de-Caixa-Eletr-nico-SENAI
Simulador de Caixa Eletrônico  Trabalho desenvolvido para o SENAI com o objetivo de simular um caixa eletrônico.  Funcionalidades  Consulta de saldo  Saque  Depósito  Salvamento do saldo em arquivo  Objetivo  Praticar variáveis, estruturas condicionais, laços de repetição e manipulação de arquivos em Python.
